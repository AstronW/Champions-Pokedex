# Champions 图鉴

## 本次交付

原生 Android 离线应用，Kotlin + Jetpack Compose，最低 Android 8.0。唯一的联网功能是详情页头图的 Champions 动图，离线或下载失败时回退内置图片。
界面按 Claude Design 稿“宝可梦图鉴应用设计”第 2 轮（v2）实现：左上角菜单打开侧边栏，分为资料（宝可梦、招式、特性、状态说明、属性克制）、对战工具（伤害计算、速度线、队伍构建）和我的（收藏与对比、设置与关于）；侧边栏底部切换外观。
中文/英文/编号搜索；筛选从底部面板选择属性、分类、排序及“全部形态 / 仅看收藏 / 含未开放”，已选条件以标签显示，点标签清除。
宝可梦详情分“基础信息 / 招式”两页：全部源形态在同一页切换（种族值位置不变，显示相对通常形态的差值）、Lv50 最高实数值、特性、体重、受到的属性伤害；头图、列表行、学习者网格与队伍格子以主属性颜色填满整块；底部可加入队伍或带入伤害计算。招式与特性详情结构相同：头图、（招式）威力/命中/PP/优先度与可横向滚动的分类标签、独立的游戏说明卡片，下方平铺 52poke 百科正文（原生渲染；署名只保留一行来源及修订号、许可链接，转换说明在“设置与关于”），再列可学会/拥有的宝可梦网格；百科内链接可跳转到对应条目。招式列表只显示已开放招式，未开放招式仍可从宝可梦学习表（“含未开放”）和百科链接进入。
设计稿中的“道具”页和身高没有对应的图鉴数据，未加入；设计稿示例数据未使用，全部内容来自现有 `dex.json`、计算器资源与 Champions 图片。
默认跟随系统外观，也可手动选择亮色和暗色；设置、收藏与队伍持久化。
启动时先解析数据并解码全部形态图片，进度条走完后才显示列表，首屏与最初的滚动不再等待图片；计算器数据随后在后台解析。
队伍构建点击成员打开二级菜单，配置形态、特性、道具、能力调整与 4 个招式（仅限该形态已开放的学习招式）。队伍属性分析计入特性与道具：飘浮类特性、吸收/减半类特性、过滤类特性、气球、黑色铁球与抗性树果（按生效一次）；携带对应超级进化石时按超级形态的属性与特性计算，超级形态以“原形态 + 进化石”保存。打击面按招式实际属性统计：冰冻皮肤、妖精皮肤、飞行皮肤、龙皮肤、湿润之声、胆量、冷冻干燥、飞身重压、怒牛及自身天气/场地对气象球、大地波动的影响；固定伤害招式只计是否无效。
伤害计算与队伍构建的二级菜单从底部滑入、关闭时滑出（减少动态效果时不做动画），覆盖在计算结果之上而不被结果卡片遮挡，可按住顶部小条或标题行下拉关闭；旋转、切换主题等重建时保持打开，切换到其他页面或进入详情再返回时为关闭状态。
队伍构建右上角“分享”生成队伍图片（按当前外观；每位成员显示形态与属性、“道具 · 特性”一行、能力调整，招式两行各两个，所有招式统一为 14 dp Champions 属性图标与 9 sp 文字，最长的 6 字招式名也完整显示；图片固定按 380 dp 宽、字体缩放 1 排版，各设备导出一致，预览在窄屏上等比缩小），预览后可调用系统分享，或保存到本地：Android 10 起直接存入相册 Pictures/ChampionsDex，无需存储权限；Android 8–9 由系统文件选择器选择保存位置。分享经 FileProvider 只暴露应用缓存中的这一张图片。
视觉使用设计稿的 Organic 设计系统：米色/墨色底、陶土橙与橄榄绿强调色、胶囊形控件与大圆角卡片，属性色按 OKLCH 统一明度。标题 Caprasimo、正文 Figtree 随应用打包（OFL 1.1），中文由系统字体显示。

打开返回栈中已有的页面时，回到原条目并保留其状态，移除上方路径，不重复叠加同一页面。进入页面从右侧滑入，返回时向右退出、原页面从左侧恢复；开启减少动态效果后不执行位移、淡入淡出或尺寸动画。

## 数据约束

招式和特性列表提供详细分类入口；详情中显示百科分类、招式目标、可展开的特殊判定及所提及的状态。分类页区分成员招式、相关招式、相关特性和段落提及，不将条件关联合并为无条件分类。游戏接触标记与百科判定分别显示，空标记显示“百科未标明”。

侧边栏“状态说明”可检索状态、天气和别名；状态详情分别展示 Champions 游戏说明与百科摘录，并可返回引用它的招式或特性。状态资料按页面 ID 合并别名，保留历史及其他游戏语境；引用不表示该状态在 Champions 中可用。百科正文中的分类与状态链接可在应用内离线打开，页面状态继续按返回栈条目保存。

- 从 champout 最新且完整的 manifest 导入；校验源指纹及产物散列，不修改源仓库或旧编辑数据库。
- 保留 personal ID 前导零，单属性按两字段相等判断；招式主表保留不可用记录，默认仅显示 available=true。
- 游戏 PP、动态威力、特殊命中值按当前数据表达，不套用其他作品数值。
- Wiki 段落来自 expanded，保留版本语境；转换展示标记不改变内容，不使用旧草稿替代最新提取数据。
- 分类、特殊判定、目标、状态引用来自 champout 的 `wiki_*` 导出。状态优先使用 `effect_expanded`；无效果节的天气页选取“影响对战”，其余使用概述。完整状态原文、分类来源和未裁剪记录保留在 `data/status-sources.json`、`data/mechanics-sources.json`、`data/mechanics-records.json`；运行时 `mechanics.json` 只携带展示所需字段。
- 图片只取 sprites 的 generation-ix/champions 目录。PokeAPI 元数据仅用于关联文件编号。缺图显式标识，不能冒充正确形态。
- 详情页头图在 Android 9+ 从同一目录的固定提交下载 512px 动画 WebP（`AnimatedSprites.kt`，文件 ID 与内置 PNG 相同）：先取当前形态与配色，显示后在不计流量网络上依次预取其他形态与异色；先显示内置 PNG（右上角小转圈表示正在下载），动图就绪后淡入替换，失败则保留 PNG；缓存在应用 cache 目录，超过 256MB 按最近使用淘汰，设置页“缓存”卡片显示占用并可一键清除。减少动态效果时停在首帧。
- 记录来源版本、链接、修订 ID、哈希和图片缺失清单。

## 验证与交付

数据导入和图片映射自动检查；Android 构建、lint、单元测试；使用独立 Android 模拟器检查真实页面、深浅主题、查询、跳转、收藏和旋转。
交付 APK、源码、可重复执行的导入/构建脚本、操作说明和验证记录。

## 伤害计算器扩展

Champions 计算规则从邻目录 damage-calc 移植为 Kotlin 原生代码，原生 Compose 界面，离线运行。游戏数值继续遵守 champout 数据合同；不修改上游仓库。详细输入、输出语义、来源版本、更新流程及验证边界见 `CALCULATOR.md`。
