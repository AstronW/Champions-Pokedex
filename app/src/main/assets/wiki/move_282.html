攻击目标造成伤害。 如果目标持有可被拍落的携带物品，则目标在战斗结束前失去其携带物品，且本次攻击的威力×1.5。 • 以下携带物品不可被拍落： • • 特性为多属性的宝可梦携带的物品第四世代 • • 可使携带者进行超级进化的超级石 • • 固拉多携带的朱红色宝珠 • • 盖欧卡携带的靛蓝色宝珠 • • 帝牙卢卡携带的大金刚宝玉 • • 帕路奇亚携带的大白宝玉 • • 骑拉帝纳携带的大白金宝玉 • • 阿尔宙斯携带的石板 • • 盖诺赛克特携带的卡带 • • Ｚ纯晶 • • 银伴战兽携带的存储碟 • • 苍响携带的腐朽的剑 • • 藏玛然特携带的腐朽的盾 • • 大部分悖谬宝可梦携带的驱劲能量 • • • 乐园守护龙除外。 • • • 破空焰、猛雷鼓、铁头壳和铁磐岩携带的驱劲能量也可以被拍落。 • • 厄诡椪携带的面具 • 如果目标携带以上不可被拍落的道具，则威力加成不适用。 • 当目标宝可梦携带以下道具时，招式令目标失去携带道具的效果会先于道具效果触发： • • 文柚果、勿花果、枝荔果等ＨＰ低于一定比例后触发的树果，亚开果 • • 树果汁 • • 红牌、逃脱按键、白色香草、模仿香草、避难背包 • • 谜芝果、嘉珍果第四世代及以前 • 如果目标携带以上道具，招式攻击时这些道具的效果不会发动。 • 当目标宝可梦携带以下道具时，道具效果会先于招式令目标失去携带道具的效果触发： • • 直接参与伤害计算的道具： • • • 进化奇石、金属粉、奇妙空间下的突击背心等改变目标防御的道具。 • • • 当恶属性招式对目标效果绝佳时的刺耳果 • • • • 当招式受使用者一般皮肤特性下变为一般属性时的灯浆果 • • • • 当招式受使用者一般皮肤特性下变为一般属性后，受等离子浴或输电效果变为电属性对目标效果绝佳时的烛木果 • • • 气势披带 • • • • 若招式未能触发道具效果，目标会因招式效果失去携带物品。 • • • 气势头带 • • • • 道具判定触发后，目标会因招式效果失去携带物品。 • • 谜芝果第五世代后、弱点保险 • • • 如果攻击造成目标陷入昏厥状态，目标会因招式效果失去携带物品。 • • • 若招式对目标并非效果绝佳，目标会因招式效果失去携带物品。 • • 嘉珍果第五世代后 • • • 如果使用者拥有魔法防守特性，嘉珍果的效果不会触发，目标会因招式效果失去携带物品。 • • 凸凸头盔 • • • 道具效果触发后，目标会因招式效果失去携带物品。 • • • 如果攻击造成目标陷入昏厥状态，目标不会因招式效果失去携带物品。 • • 附着针 • • • 如果因使用者拥有道具等情况附着针无法转移到使用者上，目标会因招式效果失去携带物品。 • • 气球 • • • 目标受到招式伤害后，气球就会爆炸消失。目标无法因招式效果失去携带物品。 • • 充电电池 • • • 招式变为电属性后，目标的充电电池会触发效果而消耗掉。目标无法因招式效果失去携带物品。 • 即使由于这些道具被消耗等原因而未能令目标失去携带道具，威力加成仍然适用。 • 招式的效果不是追加效果。 • • 招式命中拥有鳞粉特性或携带密探斗篷的目标，目标会正常失去其携带物品。 • • 如果使用者拥有强行特性，特性不会发动效果，招式命中的目标会正常失去其携带物品。 • 如果拍落命中目标的替身或拥有黏着特性的目标，则招式只会造成伤害，目标不会失去其携带物品，但威力加成仍然适用。 • • 如果攻击造成拥有黏着特性的目标陷入濒死状态，目标会正常失去其携带物品。 • 如果目标拥有轻装特性，招式令目标失去其携带物品后，目标的轻装特性会发动。 • • 目标发动特性后交换下场后再次上场，再次受到拍落目标的轻装特性也不会发动。 • 如果招式伤害被目标的画皮、结冻头所防住，目标也会失去其携带物品。 • 如果使用者因目标的铁刺特性、粗糙皮肤特性或凸凸头盔而陷入濒死状态，则目标不会失去其携带物品，但威力加成仍然适用。 • • 如果使用者因自身携带的生命宝珠而陷入濒死状态，目标会正常失去其携带物品。 • 如果使用者拥有魔术师特性，则目标首先失去其携带物品，魔术师特性因而不会发动。 • 如果目标拥有笨拙特性，或受到查封、魔法空间状态影响，目标会正常失去其携带物品，威力加成仍然适用。 • 目标失去的携带物品在战斗结束后还原。 • 野生宝可梦无法通过拍落使玩家的宝可梦失去携带物品。 拍落在极巨团体战中会使用失败，既无法拍落道具，又无法造成伤害。
